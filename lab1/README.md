# Лабораторная работа №1 - Анализ предметной области
  
## Цель 
Научиться выделять сущности, связи и бизнес-правила из текстового описания предметной области.
  
## Содержание работы 
Студент должен: 
- проанализировать текст варианта; 
- выделить основные сущности предметной области; 
- сформулировать бизнес-правила и ограничения; 
- определить связи между сущностями и их кратность. 
  
## Отчетные материалы 
- нумерованный список бизнес-правил; 
- список выделенных сущностей; 
- матрица связей сущностей с указанием кратности.
