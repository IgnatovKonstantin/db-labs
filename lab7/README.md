#Лабораторная работа №7 - Оптимизация и анализ выполнения запросов
  
##Цель 
Научиться анализировать планы выполнения SQL-запросов, выявлять причины низкой производительности и обоснованно выбирать способы оптимизации. 

##Содержание работы 
Необходимо выбрать 2 сложных запроса (для воспроизводимости задачи) из своей предметной области. 
Тестирование выполняется на объёме данных, достаточном для проявления различий между планами выполнения. 
  
###Для каждого запроса необходимо: 
1. Получить исходный план выполнения с помощью: 
EXPLAIN (ANALYZE, BUFFERS) 
2. Проанализировать:
- фактическое время выполнения; 
- количество обработанных строк; 
- cost; 
- соответствие rows и actual rows; 
- способы доступа к таблицам (Seq Scan, Index Scan, Index Only Scan, Bitmap Scan); 
- используемые алгоритмы соединения (Nested Loop, Hash Join, Merge Join); 
- операции сортировки и агрегирования; 
- количество обращений к буферам. 
3. Определить узкие места запроса и возможные причины их появления. 
4. Выполнить оптимизацию с использованием одного или нескольких способов: 
- создание или изменение индексов; 
- составные индексы; 
- частичные индексы; 
- покрывающие индексы; 
- изменение структуры SQL-запроса; 
- устранение избыточных операций; 
- изменение порядка или способа получения данных.
  
Выбранные способы оптимизации должны быть обоснованы особенностями конкретного 
запроса. Создание индекса без объяснения его назначения не считается выполнением 
требования.
  
5. Выполнить: 
ANALYZE; 
и повторно получить план выполнения. 
6. Сравнить состояние до и после оптимизации. 
Для каждого изменения необходимо объяснить: 
- почему планировщик выбрал исходный план; 
- какое изменение было внесено; 
- как изменился план выполнения; 
- почему произошло изменение производительности; 
- какие недостатки имеет предложенная оптимизация.
  
##Дополнительное задание 
Продемонстрировать ситуацию, в которой наличие индекса не приводит к его использованию планировщиком, и объяснить причину. 
  
##Отчетные материалы 
- SQL-код исследуемых запросов; 
- объём используемых тестовых данных; 
- планы EXPLAIN (ANALYZE, BUFFERS) до оптимизации; 
- выявленные проблемы; 
- выполненные изменения; 
- планы после оптимизации; 
- сравнительная таблица показателей; 
- обоснование выбранных индексов и стратегий выполнения запросов.
