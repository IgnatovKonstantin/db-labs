# Лабораторная работа №3 - Функциональная модель системы 
  
##Цель 
Определить, как данные используются и изменяются в бизнес-процессах предметной области. 
  
##Содержание работы 
Студент должен: 
- выделить основные функции и бизнес-процессы системы; 
- определить используемые ими данные; 
- построить FA-диаграмму; 
- обеспечить согласованность функциональной модели с результатами ЛР1 и ЛР2.
