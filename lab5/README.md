# Лабораторная работа №5 - Аналитические SQL-запросы
  
##Цель 
Освоить сложные запросы и аналитические возможности SQL. 
  
##Обязательные требования к запросам 
Необходимо реализовать 5 содержательно различных SQL-запросов. 
В совокупности запросы должны использовать: 
- не менее двух CTE; 
- агрегатные функции; 
- GROUP BY и HAVING; 
- различные типы соединений; 
- оконные функции.
  
##Необходимо реализовать: 
1. Сложный JOIN не менее 3 таблиц с фильтрацией, группировкой и HAVING. 
2. Поиск отсутствующих или несвязанных данных с использованием LEFT JOIN ... IS NULL или эквивалентной конструкции. 
3. Аналитический запрос с оконной функцией и явным ROWS BETWEEN. 
4. Анализ изменения значения с использованием LAG или LEAD. 
5. Ранжирование или сравнительный анализ с использованием ROW_NUMBER, RANK, DENSE_RANK, NTILE или другой оконной функции. 
  
##Отчетные материалы 
- SQL-код запросов; 
- примеры выполнения; 
- краткое описание логики каждого запроса
