# Лабораторная работа №4 - Физическая реализация базы данных
  
##Цель 
Реализовать спроектированную модель данных средствами СУБД. 
  
##Содержание работы 
Студент должен: 
- разработать физическую схему БД (DDL); 
- определить типы данных, ключи и ограничения целостности; 
- реализовать связи между таблицами и правила удаления/обновления данных; 
- подготовить начальные и тестовые данные; 
- автоматизировать создание и пересоздание базы данных; 
- обеспечить соответствие физической схемы результатам ЛР2. 
  
Тестовые данные должны быть достаточны для выполнения последующих лабораторных 
работ. 
  
## Отчетные материалы 
- SQL-скрипт создания схемы; 
- SQL-скрипт начального наполнения; 
- скрипт генерации тестовых данных на Python или другом языке; 
- инструкция по запуску и пересозданию базы данных.
