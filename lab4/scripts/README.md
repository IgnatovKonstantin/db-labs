## Состав директории scripts/ ЛР №4
| Файл | Назначение |
|---|---|
| `create.sql` | Удаление прежней структуры и создание ENUM-типов и таблиц с ограничениями целостности |
| `insert.sql` | Начальное наполнение базы данных основными данными: продавцы, договоры, товары, предложения, история цен и схем исполнения, акции и участие в них |
| `generate.py` | Генерация заказов и связанных документов на основе данных, уже находящихся в БД |
| `insert_big.sql` | Дополнительный полный фиксированный пример наполнения базы данных: основа площадки и готовые сценарии покупок, возвратов, спора и расчетов |
| `README.md` | Инструкция по запуску и пересозданию базы данных |

Основной порядок: **`create.sql -> insert.sql -> generate.py`**.

## Требования
- PostgreSQL 18 и pgAdmin 4
- Python 3.10+
- Библиотеки `Faker`, `psycopg2`

## Запуск
### 1. Подготовка окружения 
Установить библиотеки
```bash
python -m pip install Faker psycopg2-binary
```
### 2. Создание базы данных
В pgAdmin 4 выбратьDatabases -> Create -> Database.  
Указать имя `marketplace_ozero` и кодировку UTF-8.

### 3. Создание структуры
Открыть Query Tool для базы `marketplace_ozero` и выполнить весь файл `create.sql`

### 4. Начальное наполнение
В том же Query Tool открыть и выполнить весь файл `insert.sql`. 

### 5. Генерация тестовых данных
Проверить настройки подключения к БД в `generate.py`:
```python
db_config = {
    'dbname': 'marketplace_lake',
    'user': 'postgres',
    'password': 'ваш_пароль',
    'host': 'localhost',
    'port': 5432
}
```
При необходимости изменить пользователя, адрес сервера или порт.  
Запустить из папки проекта:
```bash
python generate.py
```

Ввести пароль пользователя PostgreSQL.   

При успехе появится сообщение **"Все данные сохранены"**.   
Требуемый объем задается в вызове `generate_all(num_orders=200)` внизу файла.

## Пересоздание базы данных
В существующей базе данных `marketplace_ozero` выполнить действия в следующем порядке:
1. Выполнить `create.sql` в Query Tool
2. Выполнить `insert.sql` в Query Tool
3. Запустить `python generate.py` в терминале

Скрипт `create.sql` удаляет прежние таблицы и данные, затем заново создает структуру.  
Повторное создание БД через pgAdmin 4 не требуется.    
Повторный запуск только `generate.py` добавляет новые заказы и расчеты к прежним данным. 

## Что делает генератор
`fetch_dictionary()` загружает существующих продавцов, предложения, договоры, цены и акции. Затем скрипт создает покупателей и сотрудников через Faker, выбирает покупки и рассчитывает связанные документы. Для FK используются ID существующих записей и ID, возвращенные PostgreSQL после новых вставок. SQL-скрипт `insert_big.sql` с полным примером во время работы генератора не читается - данные загружаются из БД.

Генерируются позиции заказов, платежи, отправления, поручения продавцам, возвраты, споры, решения и финансовые операции. Цена и скидка выбираются на дату заказа, платеж равен сумме позиций. Поручения создаются для склада продавца, финансовые продажи - после доставки, удержания - по обработанным возвратам.
